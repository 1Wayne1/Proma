# 交付可复用的本地工具

先确定下次使用时用户会提供什么输入，以及希望拿到什么结果。需要交互界面时，在当前会话授权的项目目录内生成可打开的 HTML 或扩展已有应用。需要调用已配置的 MCP、记忆或浏览器工具时，把这些步骤留在 Proma Agent 工作流中，由当前会话提供相应权限。

用一份合成输入核对正常结果，再试一次空输入。需要预览时遵循 `in-app-browser` 的本地文件流程。完成后通过 `Present` 交付实际存在的入口文件。假设当前授权目录里已生成 `report/index.html`，工具参数为：

```json
{"files":[{"path":"report/index.html","description":"打开本地报告工作台"}]}
```

交付时说明如何重新打开、替换输入及保存结果。网页可独立使用的部分应随文件交付。依赖当前会话的操作，在使用说明中明确指出所需的 Proma 工具。
